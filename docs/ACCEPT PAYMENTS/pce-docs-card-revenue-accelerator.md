# Overview

PCE’s Revenue Accelerator brings together cost-saving and revenue-boosting features—Interchange Optimizer and Cost Recovery—to help you maximize net transaction value. By lowering interchange fees and automating surcharges, you can unlock more profit on every payment.

**In this guide you’ll learn**  

* How to reduce your interchange costs with enhanced transaction data  
* How to offset processing fees through automated surcharges  
* How to monitor and optimize overall payment revenue

### Prerequisites & limitations

* Active merchant account with Interchange Optimizer and surcharge features enabled  
* PCI DSS Level 1 compliance for fee-related operations  
* Card-network and state approvals for surcharge application  

# Feature table

| Feature               | Description                                                                      |
| --------------------- | -------------------------------------------------------------------------------- |
| Interchange Optimizer | Submit Level 1–3 data to qualify for lower interchange rates                     |
| Cost Recovery         | Automatically calculate and apply merchant-configured surcharges on credit cards |

# Key details

## [Interchange Optimizer](doc:pce-docs-interchange-optimizer)

Provide Level 1, 2, and 3 details in your CARD transactions—like billing, PO numbers, line-item data, and tax amounts—to unlock corporate and commercial interchange tiers and reduce processing fees.

## [Cost Recovery](doc:pce-docs-cost-recovery)

Enable the Mx Advantage surcharge feature, preview surcharge amounts via API, and automatically apply configured fees to eligible credit-card transactions to recoup processing costs.
